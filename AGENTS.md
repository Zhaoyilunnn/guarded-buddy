# Repository Instructions

- Write all repository documentation in English. This includes Markdown files, diagrams, diagram source data, examples, and explanatory text.
- Write all code comments and documentation comments in English.
- User-facing output, localization strings, report templates, test fixtures, and test data may use other languages when required by product behavior or test coverage.
- Keep CLI documentation, configuration examples, and diagrams aligned with the implemented behavior. Update them together whenever a command, option, default, or workflow changes.
